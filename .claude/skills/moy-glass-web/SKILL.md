# Стиль «тёплый glass / paper» (moy-glass-web)
## Палитра — 8 переменных (менять только их)
--surface:#F3F1EC; /* фон страницы (тёплый бумажный) */
--surface-hi:#FBFAF7; /* центр радиального свечения фона */
--ink:#161513; /* заголовки и тёмный текст */
--sub:#57544D; /* вторичный текст */
--muted:#8E897E; /* лейблы, подписи */
--accent:#EE9B45; /* главный акцент: кнопки, цифры, точки (тёплый оранжевый) */
--accent-2:#C3A9DC; /* второй акцент: ghost-кнопка, orb (прохладная лаванда) */
--line:#E4E0D7; /* тонкие разделители */
Производные считаются через color-mix, вручную не трогать:
--glass:rgba(255,255,255,.46); --glass-bd:rgba(255,255,255,.7);
--accent-pulse:color-mix(in srgb,var(--accent) 55%,transparent);
--featured-b:color-mix(in srgb,var(--accent) 12%,#fff);
--featured-bd:color-mix(in srgb,var(--accent) 35%,#fff);
## Шрифты (Google Fonts)
- Handjet 800 — ВСЕ заголовки, цифры, суммы. uppercase, line-height .9.
- Inter 300-700 — текст, кнопки, лейблы. letter-spacing -.01em.
Типошкала через clamp(): h1 clamp(38px,7vw,92px), h2 clamp(34px,6vw,66px).

## Главные приёмы
1. Radial-фон: radial-gradient(120% 80% at 50% 28%, var(--surface-hi), var(--surface) 62%).
2. Handjet CAPS-заголовки + маленький акцентный квадрат в конце строки.
3. Матовое стекло на карточках: background var(--glass) + backdrop-filter blur(18px) +
рамка + мягкая тень, радиус 24px.
4. Orb: размытый градиентный шар за hero, тёплый→холодный тон акцентов.
5. Кнопки-пилюли с пульсом: primary оранжевый, ghost лавандовый. radius 100px, uppercase.
6. Date-pill с «живой» пульсирующей точкой у даты/статуса.
7. Featured-карточка: тёплый градиент #fff → featured-b с акцентной рамкой и тенью.
8. Бегущая строка Handjet, где нечётные слова — контурные (text-stroke акцентом).
## Анти-паттерны
- Тёмный/чёрный фон — стиль строится на светлой бумаге со свечением.
- Больше двух акцентов, неон, кислотные градиенты.
- Заголовок обычным шрифтом вместо Handjet CAPS.
- Плоские карточки без backdrop-blur и стеклянной рамки.
- Кнопки без пульса.
- Ручная правка производных цветов вместо смены 8 базовых переменных.
